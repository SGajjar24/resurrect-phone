05. The Universal AI Hardware Resurrection Prompt

Have an old phone in your drawer? Plug it into your PC, open Claude Code, Gemini CLI, Cursor, or ChatGPT, and paste this master prompt. The AI will inspect, debloat safely, and build your appliance automatically:

Master AI Agent Prompt 
You are an expert embedded Android system engineer and hardware revitalization specialist.
I have connected an older Android device (Android 4.4 to 10+) via USB with USB Debugging enabled.
Our goal is to transform this device from discarded digital scrap into a dedicated, single-purpose hardware appliance.

Follow this 5-phase execution plan:

1. HARDWARE RECONNAISSANCE:
   - Check device: `adb devices`
   - Inspect specs: `adb shell getprop ro.product.model`, `adb shell wm size`, `adb shell wm density`, `adb shell cat /proc/meminfo`
   - SAFETY CHECK: Ensure `wm density` does NOT have an `Override density: 0` set (causes infinite SystemUI crash). If so, run `adb shell wm density reset`.

2. SAFE DEBLOATING (USER 0 ONLY):
   - List packages via `adb shell pm list packages`.
   - Remove carrier/telemetry junk via `pm uninstall -k --user 0 `.
   - NEVER touch: com.android.systemui, com.android.settings, com.android.providers.settings, com.android.phone, com.android.server.telecom.

3. APPLIANCE UI ARCHITECTURE:
   - Build a native zero-dependency Java app (no Flutter/React Native bloat).
   - High-contrast obsidian dark theme (#12100E) with brass gold accents (#FFB300).
   - Oversized touch targets (64dp height) and visual icon badges for senior motor accessibility.
   - Pinned bottom player dock with on-screen Volume, Play/Pause, Stop, and Sleep Timer.
   - Set as launcher via <category android:name="android.intent.category.HOME" /> in AndroidManifest.xml.

4. KIOSK HARDENING:
   - Enable Immersive Sticky full-screen mode (SYSTEM_UI_FLAG_IMMERSIVE_STICKY) to permanently hide the navigation bar.
   - Configure stay-awake on charge: `adb shell settings put global stay_on_while_plugged_in 3`.
   - Add BootReceiver with RECEIVE_BOOT_COMPLETED to launch the app on power-on.

5. NATIVE ZERO-DEPENDENCY COMPILATION:
   - Compile with AAPT + javac --release 8 + D8 + apksigner.
   - Install APK via `adb install -r <app.apk>`, test live on screen, and verify PID stability.

Begin Phase 1 now by probing the connected ADB device.

06. Zero-to-Appliance: Complete Setup (From Scratch)

Starting with an old phone pulled fresh from a drawer? Follow these exact steps to unlock, authorize, and provision your hardware:

Step 0: Factory Reset & Bypass Setup Wizard

Wipe old PINs and accounts in Settings ➔ Backup & Reset ➔ Factory Reset. When it reboots, tap Skip for SIM, Skip for Google Account, and Skip for Lock Screen. Connect to Wi-Fi.

Step 1: Unlock Developer Options (The "7-Tap Secret")

Go to Settings ➔ About phone. Find Build number and tap it 7 times rapidly until the popup says "You are now a developer!".

Step 2: Enable USB Debugging & Connect Cable

Go to Settings ➔ Developer options ➔ Toggle USB Debugging ON. Plug phone into PC with a data cable. When prompted on the phone screen, check ☑ Always allow from this computer and tap OK.

Step 3: Install ADB on PC (Run in PowerShell / Terminal)
winget install Google.PlatformTools # Windows # or on macOS: brew install android-platform-tools # or on Linux: sudo apt install adb

Verify with adb devices. It should report your phone serial followed by device.

Step 4: Run Automated Turnkey Appliance Provisioner
git clone https://github.com/SGajjar24/resurrect-phone.git cd resurrect-phone powershell -ExecutionPolicy Bypass -File scripts/setup_appliance.ps1
Step 5: Lock as Permanent Home Launcher

Press the phone's Home button ➔ When prompted "Complete action using" ➔ Select શ્રી ભક્તિ સંગ્રહ (BhaktiPlayer) ➔ Tap ALWAYS. The phone is now permanently locked into your dedicated appliance!
